1. Entity-Relationship Topology (ERD)

[TABLE] SENSORS_DB
PK: id (INTEGER)
  • • name (VARCHAR(64), UNIQUE)
  • • system (VARCHAR(64))
  • • location (VARCHAR(128))
  • • type (VARCHAR(64))
  • • frequency (VARCHAR(32))
1 : N → Feeds Telemetry Channels
[TABLE] LATEST_TELEMETRY
PK: (car_id, timestamp)
  • • lap, total_laps (INT)
  • • track_phase (VARCHAR(64))
  • • speed_kmh (INT), crashed (BOOL)
  • • tyre_surface_temp_c (FLOAT)
  • • tyre_pressure_psi (FLOAT)
  • • front_brake_temp_c (FLOAT)
  • • fuel_remaining_kg (FLOAT)
  • • fuel_flow_rate_kgh (FLOAT)
  • • head_accel_g (FLOAT)
1 : 1 → Evaluated by INTERLOCKS
[TABLE] INTERLOCK_STATUS
FK: telemetry_timestamp
  • • tyre_status (ENUM)
  • • tyre_psi_warning (BOOLEAN)
  • • brake_status (ENUM)
  • • fuel_status (ENUM)
  • • head_status (ENUM)
  • • critical_trip (BOOLEAN)
  • • active_trips (JSON_ARRAY)
1 : N → Triggers LATCHED_ALARMS
[TABLE] LATCHED_ALARMS
PK: code (VARCHAR(48))
  • • metric (VARCHAR(48))
  • • value (FLOAT)
  • • threshold (FLOAT)
  • • message (VARCHAR(256))
  • • latched_at (FLOAT EPOCH)
Persists until POST /interlocks/reset

2. Table Definition: SENSORS_DB (F1 Sensor Channel Registry)

Column Data Type Constraints Default / Example Description
id INTEGER PRIMARY KEY, AUTO_INCREMENT 1 .. 6 Unique identifier for each registered telemetry sensor channel
name VARCHAR(64) NOT NULL, UTF-8 tyre_surface_temp_c Telemetry JSON key (supports UTF-8 / Cyrillic / Chinese identifiers)
system VARCHAR(64) NOT NULL 1. Tyres Parent F1 subsystem (1. Tyres, 2. Brakes, 3. Fuel, 4. Driver Earpiece)
location VARCHAR(128) NOT NULL 4-Corner Wheel Hub IR Array Physical mounting location on the F1 chassis
type VARCHAR(64) NOT NULL Temperature (80.0–135.0 °C) Physical unit, nominal operating window, and interlock threshold
frequency VARCHAR(32) NOT NULL 2 Hz (0.5s) MQTT publishing rate on topic telemetry/car/1

3. Table Definition: LATEST_TELEMETRY & Security Validation Bounds (TELEMETRY_SCHEMA_BOUNDS)

Column Type Security Validation Bounds Track Sim Range Safety Interlock Rules
car_id VARCHAR(64) Non-empty UTF-8 string (rejects bool/null/empty) "F1-CAR-01" Chassis primary identifier
timestamp DOUBLE / FLOAT > 0.0, finite, non-boolean Unix Epoch (s) Age > 3.0s triggers LINK LOST / STALE TELEMETRY
tyre_surface_temp_c FLOAT [0.0, 250.0] °C 80.0 – 135.0 °C (35°C post-crash) <80 Cold | 80–110 Optimal | 110.1–130 Blister | >130 Puncture Hazard (LATCH)
tyre_pressure_psi FLOAT [5.0, 40.0] psi 20.0 – 25.5 psi > 24.5 psi triggers Over-Inflation Warning
front_brake_temp_c FLOAT [0.0, 1500.0] °C 300.0 – 1050.0 °C <350 Cold | 350–1000 Bite Window | >1000 Thermal Fade Alert (LATCH)
fuel_remaining_kg FLOAT [0.0, 110.0] kg 100.0 → 0.95 kg (0.95%) Monotonic downward curve to 0.9%–1.0% at Lap 15; freezes on crash
fuel_flow_rate_kgh FLOAT [0.0, 150.0] kg/h 0.0 – 100.0 kg/h > 100.0 kg/h FIA Flow Violation; 0.0 kg/h Inertia Cutoff on crash
head_accel_g FLOAT [0.0, 100.0] g 0.0 – 30.0 g (2–5g cornering) > 20.0 g Medical Concussion Interlock (LATCH + Fuel Cutoff + Cooling)
